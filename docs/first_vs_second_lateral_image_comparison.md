# 第一批与第二批侧位图像规格、黑边比较

## 结论

两批图像可以进入同一个保持纵横比的训练流水线，但原始图像域差异明显，不能把它们视为同一种导出规格：

- 第一批分辨率和像素量显著更高，画布也明显更宽。
- 第一批确实有黑边，而且以左右黑色空画布为主；明显黑边比例为 61.6%，远高于第二批的 6.1%。
- 第二批的少量明显黑边主要位于顶部和底部，方向与第一批不同。
- 当前训练配置中的 `rect=True` 和等比例缩放可以避免形变，但不会去掉空画布；第一批存在较大的有效分辨率浪费和批次特征风险。

因此，现有数据可以先按当前配置训练基线；若联合三关键点模型出现明显的批次间性能差异，优先增加“自动裁连续黑边并同步更新所有关键点和框”的对照实验。

## 比较范围与方法

| 项目 | 第一批 | 第二批 |
|---|---:|---:|
| 原始目录 | `/Volumes/E/spine_data/LAT202511` | `/Volumes/E/spine_data/20260903-侧面数据第二批/labelme-export/P202607076308` |
| 扫描图像 | 404 | 706 |
| 说明 | 包含20张无同stem JSON的PNG和1组重复图像 | 706张均有同stem JSON |

本比较复用第二批报告的同一判定口径：将图像等比例缩到宽256的灰度图；灰度值不高于5视为近黑；一行或一列中至少98%的像素近黑时视为黑色边线；从图像最外缘向内连续计数。任一侧黑边达到该方向尺寸的1%称为“明显黑边”；上下合计或左右合计达到10%称为“严重黑边”。

这里的“黑边”特指可从画布边缘连续裁掉的黑色带。没有检测到连续黑边，不等于X线背景中完全没有黑色区域。

## 对训练的影响与建议

### 1. 现有配置可以先训练基线

23类侧位模型和三关键点骨盆模型的训练入口都使用 `imgsz=1280`、`rect=True`，并关闭mosaic和mixup。Ultralytics会保持纵横比缩放并填充，不会把两批图像强行拉伸到同一宽高，因此不会产生几何形变。

但第一批图像更宽且常有左右黑边。在相同 `imgsz=1280` 下，脊柱或骨盆占据的有效像素可能更少；`rect=True` 只能减少batch内填充，不能恢复被空画布浪费的分辨率。

### 2. 不建议只对图像裁边

若裁黑边，必须对图片、YOLO框和全部关键点使用完全相同的裁剪偏移与新尺寸。只裁图不改标注会直接制造系统性错标。

按当前检测结果估算，只去掉连续黑带后：

- 第一批宽高比中位数由0.560降到0.476，保留面积中位数为92.97%。
- 第二批宽高比中位数由0.353变为0.356，保留面积中位数为100%。

第一批裁边后仍明显比第二批宽，所以裁黑边只能减弱域差异，不能完全消除真实视野和构图差异。

### 3. 联合三关键点模型应按批次分别看验证指标

联合数据集的验证集和测试集应同时包含两批来源，并分别统计第一批、第二批的关键点误差。若总体指标正常但第一批明显更差，再加入统一裁边版本做A/B实验；不要只根据总体mAP判断。

推荐实验顺序：

1. 先用当前原图、`rect=True`、`imgsz=1280`训练基线。
2. 分别评估第一批和第二批的CFH、S1左端点、S1右端点误差。
3. 如果出现显著来源差距，再重建“同步裁连续黑边”的数据集并用同一split重训。
4. 对比两版的分批指标，而不是直接覆盖原始数据集。
